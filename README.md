# Expiry Stock Scanner V5

ระบบตรวจและบันทึกวันหมดอายุสินค้าแบบ Mobile-first

## Workflow
1. สแกน Barcode จากกล้อง iPhone (เมื่อ Safari รองรับ BarcodeDetector) หรือกรอกรหัสเอง
2. ถ้าพบ Barcode เดิม เปิดรายการเดิมได้ทันที
3. ถ้าไม่พบ สร้างรายการใหม่
4. ถ่าย/เลือกรูปสินค้า
5. เลือกพื้นที่และหมวดหมู่
6. กรอกวันที่เริ่มนับ + อายุสินค้า หรือกรอกวันหมดอายุ
7. ระบบคำนวณวันหมดอายุจากอายุสินค้าได้
8. ระบบจัดสถานะ 1/2/3 เดือนอัตโนมัติ
9. Dashboard สรุปตามพื้นที่/หมวดหมู่

## พื้นที่
- พื้นที่ขาย
- Store หลังร้าน
- ตู้แช่ วอลล์

## หมวดหมู่
- น้ำดื่มทั่วไป
- เบียร์
- กาแฟ
- นม
- ขนมหนม
- ของใช้ในครัว
- มาม่า ซอง/กระป๋อง
- อาหารแช่แข็ง

## ข้อจำกัดสำคัญ
V5.1 ใช้ ZXing Browser เป็นตัวอ่าน Barcode สำรอง เพื่อให้ Safari/iPhone ที่ไม่มี BarcodeDetector ยังสามารถสแกนจากกล้องได้ โดยหน้าเว็บต้องโหลดไลบรารีจาก CDN และควรเปิดผ่าน HTTPS เช่น GitHub Pages

ข้อมูล V5 เก็บใน localStorage ของอุปกรณ์ ยังไม่มีฐานข้อมูลออนไลน์/ระบบผู้ใช้
